# Índice de documentación

- `00-proyecto/`: objetivos, estado, matriz, versiones, decisiones y responsables.
- `fases/`: cada fase tiene su propio README, pasos, pruebas y evidencia.
- `entrega/`: correspondencia con capítulos de la plantilla del informe.
- `fuentes/`: documentación oficial, referencias académicas y recurso dockerlabs.
- `decisiones/`: Architecture Decision Records (ADR).
- `operacion/`: continuidad de sesiones y reglas de recuperación.

Las capturas validadas se guardan en `evidencias/`, no embebidas de forma redundante en diez documentos.
