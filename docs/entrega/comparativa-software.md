# Comparativa y justificación de software libre — borrador

| Rol | Elegido | Alternativa propietaria | Alternativa libre | Criterio por investigar |
| --- | --- | --- | --- | --- |
| LMS | Moodle | Blackboard | Chamilo | permisos/cohortes, extensibilidad y requisitos técnicos |
| Servidor | Ubuntu Server | Windows Server | Debian | soporte, paquetes y experiencia del curso |
| DB | MariaDB | SQL Server | PostgreSQL | compatibilidad Moodle, mantenimiento y licencia |
| Contenedores | Docker | software de virtualización propietario | Podman | Compose, documentación, comunidad |
| DNS | BIND9 | Windows DNS | Unbound/dnsmasq | zonas autoritativas y herramientas |
| Proxy | Nginx | IIS | Apache/Caddy | separación TLS/backend, complejidad |
| FTP | vsftpd | soluciones FTP comerciales | ProFTPD | confinamiento, FTPS y permisos |
