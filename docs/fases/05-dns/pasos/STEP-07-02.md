# STEP-07-02 — Crear zona y registros

- Estado según fuentes: **Completado y verificado localmente (VM #1 Server)**.
- Fuente: infra/bind9.
- Responsable / revisor: `criss` (ejecutor) / agente (revisor).
- VM / fecha / hora de ejecución: `VM #1 (Ubuntu Server 26.04) — 2026-10-28 20:15`.

## Qué hacer y por qué

Revisar fragmentos `infra/bind9/named.conf.local.fragment` y `db.ctcr`, integrando con la configuración existente. Aumentar el serial al editar la zona.

## Cómo comprobarlo

`sudo named-checkconf` y `sudo named-checkzone ctcr /etc/bind/db.ctcr`.

## Resultado observado

Zona `ctcr` configurada con serial `2026102401`, SOA `ns1.ctcr.`, y registros A (`aulavirtual`, `moodle`, `@`). Comprobación sintáctica `OK` sin errores.
