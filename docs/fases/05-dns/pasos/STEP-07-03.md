# STEP-07-03 — Resolver desde Linux Mint

- Estado según fuentes: **Completado y verificado localmente (VM #2 Linux Mint)**.
- Fuente: Guía previa paso 7.7.
- Responsable / revisor: `criss` (ejecutor) / agente (revisor).
- VM / fecha / hora de ejecución: `VM #2 (Linux Mint 22.3) — 2026-10-28 20:30`.

## Qué hacer y por qué

Configurar Mint para consultar 192.168.50.1 con NetworkManager sin añadir NAT propio. Probar `getent hosts aulavirtual.ctcr` y `dig @192.168.50.1 aulavirtual.ctcr +short`.

## Cómo comprobarlo

La consulta devuelve IP prevista y el navegador puede resolver por FQDN.

## Resultado observado

Resolución verificada desde Linux Mint: `dig @192.168.50.1 aulavirtual.ctcr` responde `192.168.50.1` con flag `aa` (autoritativo). Resolución de sistema con `nslookup` y navegador web funcionando sin fallback externo.
