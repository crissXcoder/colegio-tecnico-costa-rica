# STEP-08-01 — Revisar Nginx y certificados

- Estado según fuentes: **Completado y verificado localmente (VM #1 Server)**.
- Fuente: infra/nginx/README.md.
- Responsable / revisor: `criss` (ejecutor) / agente (revisor).
- VM / fecha / hora de ejecución: `VM #1 (Ubuntu Server 26.04) — 2026-10-28 20:10`.

## Qué hacer y por qué

Confirmar puertos 80/443 disponibles antes de instalar Nginx; preparar clave y certificado autofirmado con SAN del dominio. No guardar ni capturar clave privada.

## Cómo comprobarlo

El certificado muestra SAN `aulavirtual.ctcr`, fecha y clave protegida.

## Resultado observado

Nginx 1.28.3 (`1.28.3-2ubuntu1.12`) instalado y activo. Certificado autofirmado generado en `/etc/nginx/certs/aulavirtual.ctcr.crt` con SAN `aulavirtual.ctcr` y `moodle.ctcr.test`. Apache2 deshabilitado permanentemente para liberar los puertos 80 y 443 (INC-004).

- Evidencias registradas: `EV-067` (versión Nginx, certificado SAN y sintaxis `nginx -t`).
