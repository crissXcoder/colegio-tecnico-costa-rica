# STEP-08-02 — Configurar VirtualHost proxy

- Estado según fuentes: **Completado y verificado localmente (VM #1 Server)**.
- Fuente: infra/nginx/moodle.conf.example.
- Responsable / revisor: `criss` (ejecutor) / agente (revisor).
- VM / fecha / hora de ejecución: `VM #1 (Ubuntu Server 26.04) — 2026-10-28 20:14`.

## Qué hacer y por qué

Integrar `infra/nginx/moodle.conf.example`, bind interno y proxy backend localhost. Ejecutar `sudo nginx -t` antes de recargar.

## Cómo comprobarlo

Redirección 80->443 y Nginx comunica con Moodle sin exponer DB.

## Resultado observado

VirtualHost `/etc/nginx/sites-available/aulavirtual.ctcr` configurado con redirección 301 en puerto 80 y terminación SSL en puerto 443 hacia `127.0.0.1:8080`. Comprobación sintáctica con `nginx -t` exitosa y Nginx activo.
