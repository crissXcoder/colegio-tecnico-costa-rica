# STEP-08-03 — Migrar wwwroot a HTTPS

- Estado según fuentes: **Completado y verificado localmente (VM #1 Server)**.
- Fuente: Moodle/Oksigenia docs.
- Responsable / revisor: `criss` (ejecutor) / agente (revisor).
- VM / fecha / hora de ejecución: `VM #1 (Ubuntu Server 26.04) — 2026-10-28 20:15`.

## Qué hacer y por qué

Guardar backup y comprobar que la imagen Oksigenia acepta `MOODLE_URL=https://aulavirtual.ctcr` y `MOODLE_SSL_PROXY=yes`. No cambiar la URL hasta estar listo DNS+Nginx.

## Cómo comprobarlo

Navegación, sesiones, CSS, subida de archivos y redirecciones funcionales.

## Resultado observado

`compose.yaml` actualizado con `MOODLE_URL: https://aulavirtual.ctcr`, `MOODLE_SSL_PROXY: "yes"`, y puerto enlazado a `127.0.0.1:8080:8080`. `$CFG->wwwroot` verificado como `https://aulavirtual.ctcr` y `$CFG->sslproxy: '1'` en PHP CLI (INC-005).
