# STEP-09-02 — Configurar vsftpd y certificados

- Estado según fuentes: **Completado y verificado localmente (VM #1 Server)**.
- Fuente: infra/vsftpd/vsftpd.conf.example.
- Responsable / revisor: `criss` (ejecutor) / agente (revisor).
- VM / fecha / hora de ejecución: `VM #1 (Ubuntu Server 26.04) — 2026-10-28 20:29`.

## Qué hacer y por qué

Usar `infra/vsftpd/vsftpd.conf.example` como referencia, revisar `user_sub_token=$USER`, `chroot_local_user`, permisos del directorio chroot, FTPS TLS y reiniciar solo tras validar.

## Cómo comprobarlo

`systemctl is-active vsftpd`, cliente FTPS autentica con TLS.

## Resultado observado

vsftpd 3.0.5 configurado con `user_sub_token=$USER` (INC-009), `local_root=/srv/ftp/$USER`, TLSv1.3 obligatorio con certificados institucionales, y puertos pasivos 40000:40010. Demonio activo y atendiendo en `192.168.50.1:21`.
