# PASO 02.01 — Ubuntu Server, paquetes, SSH y conectividad

> Procedimiento complementario para reconstruir fases anteriores no explicadas íntegramente en el texto pegado. No sustituye verificación en cada VM.

En Ubuntu, registrar antes el sistema y red. En un servidor recién instalado (no en una VM ya configurada):

```bash
sudo apt update
sudo apt upgrade
sudo apt install -y curl ca-certificates openssl gnupg lsb-release git dnsutils
sudo systemctl status ssh --no-pager || true
sudo ss -lntup | grep ':22 ' || true
```

Para SSH, si no está instalado y se requiere por la práctica: `sudo apt install -y openssh-server`, después comprobar `sudo systemctl status ssh --no-pager`. Antes de cambiar la red/firewall mantener acceso de consola por VirtualBox.
