# PASO 06.07 — Configurar la matrícula por cohorte

> **Naturaleza:** procedimiento reproducible derivado íntegramente de la guía compartida, con correcciones para el repositorio. **No implica que el paso esté verificado en todas las máquinas.**
>
> **Origen:** `docs/fuentes/GUIA-HISTORICA-INTEGRA.md`; capturas reales de la última bitácora cuando existen.

## Antes de ejecutar

- [ ] Identificar VM, interfaz e IP actual; no asumir la IP de otra persona.
- [ ] Inspeccionar el estado actual del servicio. Si hay datos o volúmenes existentes, respaldarlos antes de cambios.
- [ ] Registrar fecha, integrante responsable, revisor y versión vigente en la sesión de bitácora.

## Procedimiento completo y comandos originales

Entrá al curso `ADM101`.

En la sección Participantes → Métodos de matriculación, agregá un método de sincronización de cohortes, si está disponible, y seleccioná `Cohorte_Administracion`.

Repetí:

| Curso    | Cohorte autorizada       |
| -------- | ------------------------ |
| `ADM101` | `Cohorte_Administracion` |
| `DOC101` | `Cohorte_Docencia`       |
| `INF101` | `Cohorte_Informatica`    |

Si el método de sincronización de cohortes no aparece, habilitalo desde Administración del sitio → Plugins → Matriculaciones → Gestionar plugins de matriculación.

Además, comprobá que no exista automatriculación abierta ni acceso de invitados a estos cursos.

Para `profesor01`, podés usar matriculación manual en `DOC101` con el rol Profesor. No otorgués a los participantes privilegios administrativos globales.

## Correcciones y precauciones aplicables

Evitar confundir cohortes con grupos dentro de un curso. Probar matrículas efectivas, deshabilitar matrícula abierta e invitados donde corresponda. El hecho de crear cohortes no prueba aislamiento.
