## Procedimiento completo y comandos originales

Abrí:

```
sudo nano /etc/bind/named.conf.options
```

Dejá la configuración del bloque `options` así:

```
options {
    directory "/var/cache/bind";

    recursion yes;

    allow-recursion {
        127.0.0.1;
        192.168.50.0/24;
    };

    allow-query {
        127.0.0.1;
        192.168.50.0/24;
    };

    listen-on {
        127.0.0.1;
        192.168.50.1;
    };

    listen-on-v6 { none; };

    forwarders {
        8.8.8.8;
        1.1.1.1;
    };

    dnssec-validation auto;
};
```

Esto configura BIND9 para atender consultas del laboratorio y utilizar resolutores externos cuando se trate de dominios públicos.

## Correcciones y precauciones aplicables

Antes de sobreescribir BIND9 guardar su configuración actual. Un servidor puede tener otro DNS o `systemd-resolved`; comprobar puertos y dirección escuchada. El fragmento versionado está en `infra/bind9/`.
