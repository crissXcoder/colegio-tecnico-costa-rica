# EV-109 — Copia de seguridad y bloque options de BIND9

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 33–34. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [07-02](../../07-02.md).

![EV-109 — Copia de seguridad y bloque options de BIND9](EV-109.webp)

## Qué ocurre en esta captura

Se copia `named.conf.options` a `named.conf.options.bak` y se reemplaza el bloque `options`: `recursion yes`; `allow-query` y `allow-recursion` para `127.0.0.1` y `192.168.50.0/24`; `listen-on { 192.168.50.1; }`; `listen-on-v6 { none; }`; `forwarders` 8.8.8.8 y 1.1.1.1; `dnssec-validation auto`.

## Interpretación y límite de la evidencia

Limita quién puede consultar (solo la red interna) y en qué dirección escucha. Detalle a saber explicar: `allow-query` incluye `127.0.0.1`, pero `listen-on` solo tiene `192.168.50.1`, así que el propio Ubuntu no consulta a BIND9 por loopback (ver INC-013).

## Reproducir y verificar

1. Seguir el procedimiento [07-02](../../07-02.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
