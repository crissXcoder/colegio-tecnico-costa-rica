# EV-110 — Zona ctcr registrada junto a zonas de otras prácticas

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 34–35. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [07-03](../../07-03.md).

![EV-110 — Zona ctcr registrada junto a zonas de otras prácticas](EV-110.webp)

## Qué ocurre en esta captura

`named.conf.local` ya contenía las zonas `hobbier.internal`, `salazarchavarria.internal` y `examenkrystel.internal` de prácticas anteriores. Al final se agrega, recuadrada, `zone "ctcr" { type master; file "/etc/bind/db.ctcr"; allow-transfer { none; }; };`.

## Interpretación y límite de la evidencia

La zona del proyecto quedó registrada sin tocar las de otros laboratorios. Consecuencia para la entrega: si este `named.conf.local` se entrega tal cual, el profesor verá esas tres zonas ajenas; hay que saber explicarlas (riesgo R-42). `allow-transfer { none; }` impide copiar la zona desde otro equipo.

## Reproducir y verificar

1. Seguir el procedimiento [07-03](../../07-03.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
