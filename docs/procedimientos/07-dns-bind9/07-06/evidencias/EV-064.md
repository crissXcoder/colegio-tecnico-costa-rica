# EV-064 — Comprobación de resolución DNS local en Ubuntu Server

**Procedencia:** prueba de aceptación real ejecutada en la VM #1 Ubuntu Server (`192.168.50.1`). **Paso relacionado:** [07-06 — PASO 07.06 — Probar la resolución en el servidor](../../07-06.md).

![EV-064 — Comprobación de resolución DNS local en Ubuntu Server](EV-064.webp)

## Qué ocurre en esta captura

En la terminal de Ubuntu Server se ejecutan consultas directas a BIND9 para verificar la resolución de los nombres institucionales:
1. `dig @192.168.50.1 aulavirtual.ctcr +short`: responde de forma inmediata `192.168.50.1`.
2. `dig @192.168.50.1 ns1.ctcr +short`: responde `192.168.50.1`.
3. `dig @192.168.50.1 ctcr SOA +short`: retorna el registro de autoridad con el serial `2026102401`, servidor de nombres primario `ns1.ctcr.` y correo administrativo `admin.ctcr.`.

## Interpretación y límite de la evidencia

- **Qué prueba:** Demuestra que el demonio `named` responde consultas DNS locales sobre la zona institucional `ctcr`, entregando la IP `192.168.50.1` configurada en el archivo maestro de zona.
- **Límite:** Prueba únicamente la respuesta del servidor local apuntando directamente a su propia IP mediante `@192.168.50.1`. No prueba la configuración del cliente en Linux Mint ni la resolución por defecto del sistema sin especificar el servidor, lo cual se aborda en EV-065.

## Reproducir y verificar

1. Conectarse a Ubuntu Server (`192.168.50.1`).
2. Ejecutar `dig @192.168.50.1 aulavirtual.ctcr +short`.
3. Comprobar que la respuesta devuelta sea `192.168.50.1`.
