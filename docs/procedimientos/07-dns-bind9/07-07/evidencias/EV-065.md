# EV-065 — Configuración y resolución DNS remota desde Linux Mint

**Procedencia:** prueba de aceptación real ejecutada en la VM #2 Linux Mint (`192.168.50.101`). **Paso relacionado:** [07-07 — PASO 07.07 — Configurar Linux Mint para utilizar BIND9](../../07-07.md).

![EV-065 — Configuración y resolución DNS remota desde Linux Mint](EV-065.webp)

## Qué ocurre en esta captura

En la terminal de Linux Mint (`criss-VirtualBox`):
1. Se verifica la asignación del servidor DNS mediante NetworkManager: `192.168.50.1`.
2. Se ejecuta `dig aulavirtual.ctcr +short`, respondiendo inmediatamente `192.168.50.1` a través del resolver del cliente.
3. Se ejecuta `getent ahostsv4 aulavirtual.ctcr`, devolviendo la IP `192.168.50.1` con resolución POSIX nativa del sistema operativo.
4. Se ejecuta `ping -c 2 aulavirtual.ctcr`, demostrando resolución de nombres en tiempo real, 2 paquetes transmitidos, 2 recibidos, 0% de pérdida y RTT promedio de 1.35 ms.

## Interpretación y límite de la evidencia

- **Qué prueba:** Demuestra que la estación cliente de la red interna utiliza a Ubuntu Server (`192.168.50.1`) como su servidor DNS primario, resolviendo correctamente el FQDN `aulavirtual.ctcr` a nivel de red, libc y aplicaciones del sistema.
- **Límite:** Prueba la resolución de nombres y conectividad IP; no prueba la respuesta de la capa web HTTPS en el puerto 443, la cual corresponde al Paso 8.

## Reproducir y verificar

1. Conectarse a Linux Mint (`192.168.50.101`).
2. Ejecutar `dig aulavirtual.ctcr +short`.
3. Ejecutar `ping -c 2 aulavirtual.ctcr`.
4. Comprobar que responda `192.168.50.1` con 0% de pérdida.
