# EV-115 — Versión de Nginx instalada

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 38. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [08-01](../../08-01.md).

![EV-115 — Versión de Nginx instalada](EV-115.webp)

## Qué ocurre en esta captura

`nginx -v` → `nginx version: nginx/1.28.3 (Ubuntu)`.

## Interpretación y límite de la evidencia

En esta VM el paquete es `1.28.3-2ubuntu1.11`, instalado desde archivos `.deb` porque APT ya no lo ofrecía (INC-003). `nginx -v` no muestra la revisión del paquete; para eso, `dpkg-query -W nginx`.

## Reproducir y verificar

1. Seguir el procedimiento [08-01](../../08-01.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
