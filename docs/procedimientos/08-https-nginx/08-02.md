## Procedimiento completo y comandos originales

Como el dominio es local, crearemos un certificado autofirmado para el laboratorio.

Creá la carpeta:

```
sudo mkdir -p /etc/nginx/certs
```

Generá la clave privada y el certificado, con una validez de 365 días:

```
sudo openssl req -x509 -nodes -days 365 \
  -newkey rsa:3072 \
  -keyout /etc/nginx/certs/ctcr.key \
  -out /etc/nginx/certs/ctcr.crt \
  -subj "/C=CR/O=Colegio Tecnico/CN=aulavirtual.ctcr" \
  -addext "subjectAltName=DNS:aulavirtual.ctcr"
```

Protegé la clave:

```
sudo chmod 600 /etc/nginx/certs/ctcr.key
```

Verificá los datos del certificado:

```
openssl x509 -in /etc/nginx/certs/ctcr.crt \
  -noout -subject -dates -ext subjectAltName
```

El certificado debe identificar el dominio `aulavirtual.ctcr`.

El archivo reproducible está en `infra/nginx/moodle.conf.example`; la pareja cert/key debe existir y verificarse. Revisar conflictos con Apache/Nginx host y 80/443.
