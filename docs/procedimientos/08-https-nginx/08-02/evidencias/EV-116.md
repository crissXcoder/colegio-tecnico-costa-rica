# EV-116 — Certificado autofirmado con SAN y clave protegida

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 38. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [08-02](../../08-02.md).

![EV-116 — Certificado autofirmado con SAN y clave protegida](EV-116.webp)

## Qué ocurre en esta captura

`mkdir -p /etc/nginx/certs`; `openssl req -x509 -nodes -days 365 -newkey rsa:3072 -keyout /etc/nginx/certs/aulavirtual.ctcr.key -out /etc/nginx/certs/aulavirtual.ctcr.crt -subj "/C=CR/O=Colegio Tecnico de Costa Rica/CN=aulavirtual.ctcr" -addext "subjectAltName=DNS:aulavirtual.ctcr"`; `chmod 600` sobre la clave.

## Interpretación y límite de la evidencia

Clave RSA de 3072 bits, válido 365 días y con SAN para el dominio (los navegadores actuales ignoran el CN y exigen SAN). La clave no se muestra ni se entrega.

## Reproducir y verificar

1. Seguir el procedimiento [08-02](../../08-02.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
