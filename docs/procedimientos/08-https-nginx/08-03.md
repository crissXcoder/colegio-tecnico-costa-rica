## Propósito del paso y contexto operacional

Nginx y TLS: proxy inverso local, URL canónica de Moodle y publicación controlada en 443.

Este archivo corresponde **exclusivamente al paso 08-03**, con comandos históricos literales y mejoras razonadas. ## Procedimiento completo y comandos originales

En Ubuntu:

```
sudo nano /etc/nginx/sites-available/moodle
```

Pegá:

```
server {
    listen 192.168.50.1:80;

    server_name aulavirtual.ctcr;

    return 301 https://$host$request_uri;
}

server {
    listen 192.168.50.1:443 ssl;

    server_name aulavirtual.ctcr;

    ssl_certificate /etc/nginx/certs/ctcr.crt;
    ssl_certificate_key /etc/nginx/certs/ctcr.key;

    ssl_protocols TLSv1.2 TLSv1.3;

    client_max_body_size 100M;

    location / {
        proxy_pass http://192.168.50.1:8080;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto https;

        proxy_http_version 1.1;

        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
}
```

Guardá el archivo.
