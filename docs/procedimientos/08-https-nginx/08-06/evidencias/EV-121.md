# EV-121 — HTTPS 200 desde Ubuntu con cookie segura

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 41. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [08-06](../../08-06.md).

![EV-121 — HTTPS 200 desde Ubuntu con cookie segura](EV-121.webp)

## Qué ocurre en esta captura

`curl -k -I --resolve aulavirtual.ctcr:443:192.168.50.1 https://aulavirtual.ctcr` → `HTTP/1.1 200 OK`, `Server: nginx/1.28.3 (Ubuntu)`, fecha `Tue, 27 Oct 2026 03:41:31 GMT` y `Set-Cookie: MoodleSession=…; path=/; secure; HttpOnly; SameSite=Lax`.

## Interpretación y límite de la evidencia

La cookie marcada `secure` confirma que Moodle sabe que está detrás de HTTPS. `--resolve` fuerza la IP: prueba Nginx y Moodle, no el DNS del propio Ubuntu (INC-013).

## Reproducir y verificar

1. Seguir el procedimiento [08-06](../../08-06.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
