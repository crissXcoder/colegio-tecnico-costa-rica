## Procedimiento completo y comandos originales

En Firefox:

```
https://aulavirtual.ctcr
```

Como el certificado es autofirmado, Firefox puede mostrar una advertencia de confianza. Esto no significa necesariamente que HTTPS esté mal configurado.

Para el laboratorio, pueden importar ese certificado como una autoridad de confianza solamente dentro del entorno de pruebas, o continuar mediante una excepción controlada en el navegador. No deben hacerlo con certificados desconocidos de sitios reales.

Para comprobar la conexión cifrada desde Mint:

```
openssl s_client \
  -connect 192.168.50.1:443 \
  -servername aulavirtual.ctcr \
  </dev/null
```

Buscá información del certificado y el protocolo TLS negociado.

Evidencia 5: Moodle funcionando bajo `https://aulavirtual.ctcr`, más la configuración del VirtualHost y la validación `nginx -t`.

![Mint abre el aula por HTTPS y HTTP redirige](08-07/evidencias/EV-122.webp)

**Qué se observa:** En el Mint de Greilyn: `getent ahostsv4 aulavirtual.ctcr` → `192.168.50.1`; Firefox abre `aulavirtual.ctcr` con el sitio «Colegio Tecnico» y la lista de cursos; `curl -I http://aulavirtual.ctcr` → `301 Moved Permanently` con `Location: https://aulavirtual.ctcr/`.
