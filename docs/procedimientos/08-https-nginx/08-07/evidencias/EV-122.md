# EV-122 — Mint abre el aula por HTTPS y HTTP redirige

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 41–42. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [08-07](../../08-07.md).

![EV-122 — Mint abre el aula por HTTPS y HTTP redirige](EV-122.webp)

## Qué ocurre en esta captura

En el Mint de Greilyn: `getent ahostsv4 aulavirtual.ctcr` → `192.168.50.1`; Firefox abre `aulavirtual.ctcr` con el sitio «Colegio Tecnico» y la lista de cursos; `curl -I http://aulavirtual.ctcr` → `301 Moved Permanently` con `Location: https://aulavirtual.ctcr/`.

## Interpretación y límite de la evidencia

Prueba de punta a punta desde un cliente. Los nombres de cursos («Fundamentos de Seguridad Informatica», «Evaluacion y PLanificacion Educativa») y el idioma inglés son anteriores a la normalización del 24/10 (06-01, 06-03).

## Reproducir y verificar

1. Seguir el procedimiento [08-07](../../08-07.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
