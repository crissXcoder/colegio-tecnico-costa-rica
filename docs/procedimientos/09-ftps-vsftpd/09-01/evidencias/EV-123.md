# EV-123 — Instalación de vsftpd esperando el bloqueo de APT

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 42. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [09-01](../../09-01.md).

![EV-123 — Instalación de vsftpd esperando el bloqueo de APT](EV-123.webp)

## Qué ocurre en esta captura

`apt install -y vsftpd` repite `Waiting for cache lock: Could not get lock /var/lib/dpkg/lock-frontend. It is held by process 3165 (unattended-upgr)`. Después, `vsftpd -v` → `vsftpd: version 3.0.5`.

## Interpretación y límite de la evidencia

La instalación esperó a que terminaran las actualizaciones automáticas (INC-019) y luego quedó la versión 3.0.5.

## Reproducir y verificar

1. Seguir el procedimiento [09-01](../../09-01.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
