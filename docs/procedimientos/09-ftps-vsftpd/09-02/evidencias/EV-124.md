# EV-124 — Cuentas FTP con guion bajo y shell nologin

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 43–44. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [09-02](../../09-02.md).

![EV-124 — Cuentas FTP con guion bajo y shell nologin](EV-124.webp)

## Qué ocurre en esta captura

`adduser` crea `marta_jimenez`, `carlos_mendez` (Administración), `sofia_hernandez`, `jose_ramirez` (Docencia), `valeria_sanchez` y `diego_fernandez` (Informática), pidiendo la contraseña sin mostrarla. Luego un ciclo `usermod -s /usr/sbin/nologin` para las seis.

## Interpretación y límite de la evidencia

En esta VM los usuarios se crearon con **guion bajo** para evitar que `adduser` rechace el punto (INC-007). DATOS-MAESTROS y la VM de Criss usan `marta.jimenez`: los nombres FTP **no coinciden entre VMs** (P-17). `nologin` impide entrar por consola o SSH.

## Reproducir y verificar

1. Seguir el procedimiento [09-02](../../09-02.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
