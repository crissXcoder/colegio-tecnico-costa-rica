## Procedimiento completo y comandos originales

Para mantenerlos organizados:

```
sudo mkdir -p /srv/ftp
```

Creá los directorios principales y una carpeta de trabajo por usuario:

```
for u in marta.jimenez carlos.mendez sofia.hernandez jose.ramirez valeria.sanchez diego.fernandez; do
    sudo mkdir -p "/srv/ftp/$u/archivos"
    sudo chown root:root "/srv/ftp/$u"
    sudo chmod 755 "/srv/ftp/$u"
    sudo chown "$u:$u" "/srv/ftp/$u/archivos"
    sudo chmod 700 "/srv/ftp/$u/archivos"
    sudo usermod -d "/srv/ftp/$u" "$u"
done
```

Los directorios principales son propiedad de `root` para permitir un aislamiento mediante `chroot`.

La carpeta `archivos` es el único espacio donde cada cuenta puede subir y modificar su contenido.

#### EV-125 · Directorios por funcionario con permisos 700

![Directorios por funcionario con permisos 700](09-03/evidencias/EV-125.webp)

**Qué se observa:** `mkdir -p /srv/ftp` y un ciclo que, por usuario, crea `archivos/`, deja la raíz `/srv/ftp/$u` como `root:root 755`, la subcarpeta `archivos` como `$u:$u 700` y cambia el home con `usermod -d`. `ls -ld /srv/ftp/*/archivos` muestra `drwx------` para las seis cuentas (30 de octubre, 11:58 a 12:10).

**Qué significa y qué no prueba:** La raíz no escribible es requisito del chroot de vsftpd (INC-010) y `700` impide que otra cuenta lea la carpeta. **Ficha:** [EV-125](09-03/evidencias/EV-125.md).
