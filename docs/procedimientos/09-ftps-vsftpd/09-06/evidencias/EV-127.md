# EV-127 — Reinicio de vsftpd

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 44. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [09-06](../../09-06.md).

## Qué ocurre en esta captura

`systemctl restart vsftpd` y `systemctl is-active vsftpd` → `active`.

## Interpretación y límite de la evidencia

El servicio arrancó con la configuración nueva; si tuviera un valor inválido, aquí aparecería el fallo (INC-016).

## Reproducir y verificar

1. Seguir el procedimiento [09-06](../../09-06.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
