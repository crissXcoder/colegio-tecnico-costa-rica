# EV-128 — Subidas FTPS de tres departamentos

**Procedencia:** Documento del grupo «Proyecto Colegio Técnico con departamentos separados» (PDF de 54 páginas), página 44. Captura real del grupo en la VM `server@server` (usuario `server`, Ubuntu Server con `enp0s8` 192.168.50.1), distinta de la VM de Criss (`criss@server`). **Paso relacionado:** [09-07](../../09-07.md).

![EV-128 — Subidas FTPS de tres departamentos](EV-128.webp)

## Qué ocurre en esta captura

Se crean tres archivos de prueba (`expediente-administrativo.txt`, `planificacion-docente.txt`, `informe-soporte.txt`) y se suben con `curl --ssl-reqd --insecure --user <cuenta> --upload-file … ftp://192.168.50.1/archivos/…` como `marta_jimenez`, `sofia_hernandez` y `valeria_sanchez`. Las tres terminan al 100 % (43, 39 y 48 bytes); curl pide la contraseña sin mostrarla.

## Interpretación y límite de la evidencia

`--ssl-reqd` obliga a cifrar; `--insecure` solo acepta el certificado autofirmado. Prueba la escritura en la carpeta propia de una cuenta por departamento.

## Reproducir y verificar

1. Seguir el procedimiento [09-07](../../09-07.md) en la VM que se vaya a presentar.
2. Comparar la salida con esta captura; las rutas, nombres de usuario y versiones pueden variar entre VMs del grupo (ver ADR-0004).
3. Si la salida cambia, crear una evidencia nueva en lugar de reemplazar esta.
