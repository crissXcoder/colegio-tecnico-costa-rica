# PASO 10.05 — Programar Cron

> **Naturaleza:** procedimiento reproducible derivado íntegramente de la guía compartida, con correcciones para el repositorio. **No implica que el paso esté verificado en todas las máquinas.**
>
> **Origen:** `docs/fuentes/GUIA-HISTORICA-INTEGRA.md`; capturas reales de la última bitácora cuando existen.

## Antes de ejecutar

- [ ] Identificar VM, interfaz e IP actual; no asumir la IP de otra persona.
- [ ] Inspeccionar el estado actual del servicio. Si hay datos o volúmenes existentes, respaldarlos antes de cambios.
- [ ] Registrar fecha, integrante responsable, revisor y versión vigente en la sesión de bitácora.

## Procedimiento completo y comandos originales

Abrí el Cron de `root`:

```
sudo crontab -e
```

Al final agregá:

```
0 2 * * * /home/angelica/proyecto-moodle/respaldo.sh >> /var/log/moodle-backup.log 2>&1
```

Con esta configuración se ejecuta todos los días a las 2:00 a. m., según la zona horaria de Ubuntu Server.

Si otro integrante tiene un usuario diferente a `angelica`, deberá reemplazar esa parte de la ruta.

Comprobá la zona horaria:

```
timedatectl
```

Si necesitás configurar Costa Rica:

```
sudo timedatectl set-timezone America/Costa_Rica
```

Verificá Cron:

```
sudo systemctl enable --now cron
```

```
sudo systemctl is-active cron
```

Y la programación:

```
sudo crontab -l
```

Importante: la tarea solo se ejecutará si la VM está encendida a la hora programada. Para la demostración, también podemos ejecutarla manualmente.
