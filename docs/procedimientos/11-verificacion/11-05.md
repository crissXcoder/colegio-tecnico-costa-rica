# PASO 11.05 — Verificar el firewall

> **Naturaleza:** procedimiento reproducible derivado íntegramente de la guía compartida, con correcciones para el repositorio. **No implica que el paso esté verificado en todas las máquinas.**
>
> **Origen:** `docs/fuentes/GUIA-HISTORICA-INTEGRA.md`; capturas reales de la última bitácora cuando existen.

## Antes de ejecutar

- [ ] Identificar VM, interfaz e IP actual; no asumir la IP de otra persona.
- [ ] Inspeccionar el estado actual del servicio. Si hay datos o volúmenes existentes, respaldarlos antes de cambios.
- [ ] Registrar fecha, integrante responsable, revisor y versión vigente en la sesión de bitácora.

## Procedimiento completo y comandos originales

Antes de la presentación:

```
sudo ufw status verbose
```

Si UFW está activo, deben permitir los servicios necesarios desde la red interna, sin abrirlos indiscriminadamente hacia otras redes.

Ejemplo:

```
sudo ufw allow from 192.168.50.0/24 to any port 53 proto tcp
sudo ufw allow from 192.168.50.0/24 to any port 53 proto udp

sudo ufw allow from 192.168.50.0/24 to any port 80 proto tcp
sudo ufw allow from 192.168.50.0/24 to any port 443 proto tcp

sudo ufw allow from 192.168.50.0/24 to any port 21 proto tcp
sudo ufw allow from 192.168.50.0/24 to any port 40000:40010 proto tcp
```

No actives UFW automáticamente si ya existen reglas importantes. Revisá primero el estado y las reglas actuales. Si administrás Ubuntu mediante SSH, asegurate de conservar ese acceso antes de modificar el firewall.

## Correcciones y precauciones aplicables

Las reglas UFW dependen de la red y del SSH utilizado por el equipo. Registrar regla actual y ruta de rollback antes de habilitar firewall para no perder acceso.
