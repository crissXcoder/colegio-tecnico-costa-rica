## 3. Instrucciones de Carga en Moodle (`https://aulavirtual.ctcr`)

Para cada curso departamental:
1. Iniciar sesión con la cuenta del profesor correspondiente (o cuenta `admin`).
2. Activar el **Modo de edición**.
3. **Sección 1:** Subir el Recurso 1 como archivo PDF (`mod_resource`) con el nombre visible correspondiente.
4. **Sección 2:** Subir el Recurso 2 como archivo PDF (`mod_resource`) con el nombre visible correspondiente.
5. **Sección 3:** Configurar el cuestionario evaluable con el título oficial de la tabla.
