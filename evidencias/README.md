# Evidencias, índice y criterios

- [Catálogo visual con las 50 capturas](CATALOGO-CAPTURAS.md).
- [Metadatos completos en CSV (IDs, SHA256, origen, página, paso, tratamiento)](manifiesto-detallado.csv).
- La fuente es `Proyecto_Colegio_Técnico_con_departamentos_separados(1).docx` (26 páginas), aportada por el grupo.
- Las imágenes **no** constituyen evidencias de que toda la infraestructura esté completada en todas las VMs.
- Capturas con datos de cuentas o credenciales se incluyen con zonas deliberadamente ocultas. Conservar el original solo fuera de Git, en almacenamiento restringido.
- **No publicar** claves, contraseñas, tokens ni datos de estudiantes. Revisar incluso estas versiones saneadas antes de hacer público el repositorio.
- Nuevas capturas: nombre `EV-051-...` en adelante, registrando fecha, VM, comando, resultado esperado/observado y revisor.
- Tras cerrar cada requisito, registrar pruebas positivas y negativas, no solo capturas de configuración.
