6. COMANDOS DE DIAGNOSTICO RAPIDO Y RESOLUCION DE INCIDENTES
================================================================================

1. Si Moodle no responde en Firefox:
   En Ubuntu Server:
     sudo systemctl status nginx
     cd ~/proyecto-moodle && sudo docker compose ps
     sudo docker compose logs --tail=50 moodle

2. Si el dominio 'aulavirtual.ctcr' no resuelve desde Linux Mint:
   En Linux Mint:
     cat /etc/resolv.conf  (Debe decir 'nameserver 192.168.50.1')
   En Ubuntu Server:
     sudo systemctl status named
     sudo named-checkzone ctcr /etc/bind/db.ctcr

3. Si FTPS no permite conectar:
   En Ubuntu Server:
     sudo systemctl status vsftpd
     cat /etc/vsftpd.user_list  (Verificar que el usuario este en la lista)
     grep "/usr/sbin/nologin" /etc/shells  (Debe estar listada)
     sudo iptables -L -n -v | grep 40000   (Verificar puertos pasivos abiertos)

4. Si se requiere inspeccionar los logs de acceso en tiempo real:
   En Ubuntu Server:
     sudo tail -f /var/log/nginx/access.log
     sudo tail -f /var/log/vsftpd.log
